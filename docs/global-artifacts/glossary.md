# Glossary of Terms

| Term                    | Definition                                                                                                                                                                    |
|-------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **User**                | Represents an individual interacting with the system, categorized as an admin, healthcare staff (doctor, nurse, technician), or a patient.                                   |
| **Username**            | Unique identifier for a user within the system.                                                                                                                             |
| **Role**                | Designation of the user's function (Admin, Doctor, Nurse, Technician, Patient).                                                                                             |
| **Email**               | User's email address for communication and identification.                                                                                                                  |
| **Patient**             | Individuals receiving medical care within the healthcare system.                                                                                                           |
| **First Name**          | Patient's first name.                                                                                                                                                       |
| **Last Name**           | Patient's last name.                                                                                                                                                        |
| **Full Name**           | Combination of first and last name.                                                                                                                                         |
| **Date of Birth**       | Patient's birth date for identification and medical records.                                                                                                               |
| **Gender**              | Patient's gender.                                                                                                                                                           |
| **Medical Record Number**| Unique identifier assigned to each patient.                                                                                                                                 |
| **Contact Information**  | Patient's email and phone number.                                                                                                                                           |
| **Allergies/Medical Conditions** | (Optional) Information on known allergies or medical issues.                                                                                                       |
| **Emergency Contact**    | Person to be contacted in case of emergencies.                                                                                                                             |
| **Appointment History**  | Record of past and upcoming appointments.                                                                                                                                  |
| **Staff**               | Professionals who provide healthcare services.                                                                                                                              |
| **First Name**          | Staff member's first name.                                                                                                                                                 |
| **Last Name**           | Staff member's last name.                                                                                                                                                  |
| **Full Name**           | Combination of staff member's first and last name.                                                                                                                         |
| **License Number**      | Unique identifier for each healthcare professional.                                                                                                                        |
| **Specialization**      | The specific field of medicine in which the staff member is trained (e.g., cardiology, orthopedics).                                                                        |
| **Contact Information**  | Staff member's email and phone number.                                                                                                                                     |
| **Availability Slots**   | List of time slots defined by staff as available for appointments.                                                                                                        |
| **Operation Request**    | The operation that is requested for later scheduling.                                                                                                                      |
| **ID**                  | Unique identifier for the operation request.                                                                                                                                |
| **Patient ID**          | Links the operation request to a specific patient.                                                                                                                         |
| **Doctor ID**           | Links the operation request to the doctor requesting it.                                                                                                                   |
| **Operation Type ID**   | Identifies the type of operation to perform on the patient.                                                                                                               |
| **Deadline Date**       | Suggested deadline for performing the operation.                                                                                                                            |
| **Priority**            | Indicates the urgency of performing the operation.                                                                                                                          |
| **Operation Type**      | Represents predefined types of medical operations or procedures.                                                                                                            |
| **ID**                  | Unique identifier for the operation type.                                                                                                                                   |
| **Name**                | Name of the operation (e.g., appendectomy, heart bypass).                                                                                                                  |
| **Required Staff by Specialization** | List of essential staff needed for each specialization during the operation.                                                                                  |
| **Estimated Duration**   | Time expected to complete the operation type.                                                                                                                              |
| **Appointment**         | Represents a scheduled operation of a patient by a set of staff occurring in a room at a specific time.                                                                     |
| **ID**                  | Unique identifier for the appointment.                                                                                                                                     |
| **Request ID**          | Links the appointment to the operation request that initiated it.                                                                                                          |
| **Room ID**             | Identifies the specific room assigned for the appointment.                                                                                                                 |
| **Date and Time**       | Scheduled date and time for the operation.                                                                                                                                  |
| **Status**              | Current status of the appointment (scheduled, completed, canceled).                                                                                                       |
| **Surgery Room**        | Represents surgery rooms in the healthcare facility for operations.                                                                                                        |
| **Room Number**         | Unique identifier for the surgery room.                                                                                                                                     |
| **Type**                | Type of room (e.g., operating room, consultation room, ICU).                                                                                                              |
| **Capacity**            | Maximum number of patients or staff that the room can accommodate.                                                                                                         |
| **Assigned Equipment**   | List of equipment available in the room.                                                                                                                                   |
| **Current Status**      | Indicates if the room is available, occupied, or under maintenance.                                                                                                        |
| **Maintenance Slots**    | Defined time slots for room maintenance.                                                                                                                                   |
